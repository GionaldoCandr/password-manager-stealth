========================================================================
   STEALTH VAULT ECOSYSTEM (MobilePMSV, PcPMSV & Extension)
   Pusat Instalasi Lengkap (Folder /app)
========================================================================

Seluruh aplikasi, installer, dan extension telah diperbarui dengan:
- Logo stealth baru tanpa background putih (presisi & pas)
- Fitur lengkap Password Health Monitoring (skor %, deteksi sandi duplikat,
  bar kekuatan sandi real-time, filter satu-klik, rekomendasi cerdas)
- Penyesuaian nama baru: MobilePMSV, PcPMSV, extension-password-browser

------------------------------------------------------------------------
DAFTAR FILE DI FOLDER INI:
------------------------------------------------------------------------

1. ANDROID (MobilePMSV):
   - MobilePMSV.apk  /  app.apk
     -> APK Android resmi yang telah di-align (zipalign 4-byte) dan
        ditandatangani dengan Signature Scheme v2 & v3 (Anti error penguraian).
     -> Cukup kirim ke HP Android Anda (lewat USB/WA) lalu pasang.

2. PC WINDOWS (PcPMSV):
   - PcPMSV-Installer.exe  /  smart_installer.exe
     -> Setup Wizard interaktif. Memasang aplikasi ke SystemCache tersembunyi
        dan mendaftarkan alias shortcut Windows Run (Win + R).
   - PcPMSV.exe  /  app-gui.exe
     -> Aplikasi desktop standalone. Bisa dijalankan langsung tanpa instalasi.
   - launcher.exe
     -> Background process peluncur cepat tanpa jejak di disk.

3. BROWSER EXTENSION (Chrome / Edge / Brave):
   - extension-password-browser (Folder)
   - extension-password-browser.zip (File Zip)
     -> Cara pasang di browser:
        1. Buka chrome://extensions (atau edge://extensions)
        2. Aktifkan tombol "Developer mode" di kanan atas
        3. Klik "Load unpacked" (Muat yang belum dibongkar)
        4. Pilih folder "extension-password-browser" di dalam folder app ini.
